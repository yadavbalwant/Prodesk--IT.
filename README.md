# Prodesk IT Landing Page

A responsive landing page for **Prodesk IT**, focused on web development, SEO, and digital marketing.

## 🛠️ Technologies

* HTML5
* CSS3
* Bootstrap 4.5
* Font Awesome
* Google Fonts

## ✨ Features

* Responsive navigation
* Hero/banner section
* SEO, Web Development & Marketing services
* Call-to-action section
* Social media links
* CSS fade-in animations
* Responsive design


Open `index.html` directly in a browser or use **VS Code → Live Server**.
