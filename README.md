# Prodesk IT — Enterprise IT Solutions Landing Page

Prodesk IT ke liye ek modern, fast aur responsive landing page[cite: 1, 2, 3]. Isme dark mode support, smooth scroll animations aur dynamic features diye gaye hain[cite: 1, 2, 3].

---

## 🚀 Features

* **Dark Mode**: Light aur dark theme toggle karne ka option[cite: 1, 2, 3].
* **Responsive Design**: Mobile, tablet aur desktop sabhi devices par achhi tarah chalta hai[cite: 1, 2].
* **Smooth Animations**: Scroll karne par smooth animations dekhne ko milte hain[cite: 1].
* **Animated Stats**: Numbers scroll hone par automatically count-up hote hain[cite: 1, 2].
* **Fast & Accessible**: Clear layout aur Fast loading speed[cite: 2, 3].

---

## 🛠️ Tech Stack

* **HTML5**: Semantic layout aur web structure.
* **CSS3**: BEM methodology, Custom Properties aur Grid/Flexbox layouts[cite: 3].
* **JavaScript**: Pure Vanilla JS dynamic interactivity ke liye[cite: 1].
